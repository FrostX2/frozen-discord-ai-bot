## 🚀 Quick Start

### 1. Summon the code
```console
git clone https://github.com/FrostX2/Frozen-discord-ai-bot.git
```

### 2. Unlock the secrets
```console
cp .env.example .env
```

> [!IMPORTANT]
> Open `.env` and fill in your `CLIENT_ID`, `DISCORD_TOKEN`, `AI_BASE_URL`, `AI_API_KEY`, and `AI_MODEL`. Get your credentials from the [**Discord Developer Portal**](https://discord.com/developers/applications).

### 3. Let it snow ❄️
```console
node src/index.js
```
